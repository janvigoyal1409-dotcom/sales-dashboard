# sales-dashboard
Sales Performance & Profitability Analysis Dashboard — Power BI
 📊 Sales Performance & Profitability Analysis Dashboard — Power BI

## 📌 Project Overview
This project focuses on building an interactive **Sales Analytics Dashboard** in Power BI to help businesses monitor revenue, profitability, regional performance, and discount impact.

Many organizations struggle to identify which products and regions generate maximum profit and how discounts affect margins. This dashboard provides a centralized data-driven solution for business decision-making.

---

## 🎯 Business Problem
Businesses lacked a unified system to:
- Track sales and profit performance in real time
- Identify low-performing products and regions
- Understand the impact of discounts on profitability

---

## ✅ Solution
Developed a Power BI dashboard that transforms raw sales data into meaningful business insights through KPIs, charts, and interactive filters.

---

## 📈 Key Dashboard Features
- Product-wise Profit Analysis
- Region-wise Sales Performance
- Discount vs Profit Margin Analysis
- KPI Cards (Total Sales, Net Sales, Profit Margin)
- Interactive Filters & Drill-down Analysis

---

## 🛠 Tools & Technologies
- Power BI Desktop
- Data Modeling
- DAX Measures
- Data Visualization
- Business Intelligence Analytics

---

## 💡 Business Impact
- Enabled quick identification of profitable products
- Supported data-driven pricing and sales decisions
- Improved performance monitoring for management
